carVid

![alt text](https://www.alpine.co.uk/fileadmin/images/MainNavigation/Products/Product_pics/04_MobileMediaStations/IVE-W530BT/productpic_IVE-W530BT-01.jpg)
convertion tool for ALPINE IVE-W530BT.
  - 2din APLINE car stereo
  - WVGA 6.1" inch screen, touch (first gen?)
  - support WMA,MP3, DIVX, ACC
     

Based on youtube-dl package with the additional use of ffmpeg for second step convertion of video resolution.
  - set for nHD (ninthHD) meaning 1/9 of actual HD (1920x1080p) for the 6.1" WVGA screen
  - resolution set at 640x360 (wide boi)
  - uses full resolution from youtube, converted to mpeg4 and divx.
  - max v/a quality : 2k bitrate video, 250~ bitrate audio.
  - lvl 9000 coolness.
  - uses list, feed freely.
